# 물리 환경과 모델의 범위

이 모델은 모터 각도에서 줄 당김과 경로까지의 연결을 시험하기 위한 축약 모델이다. 계산한 값, 입력 파일의 저장값, 미측정 가정을 구분한다.

| 항목 | 근거 | 남아 있는 한계 |
| --- | --- | --- |
| 로켓 외형·상승 | ORK 치수와 저장된 위치·기체 축 방향 | 변경한 바람으로 상승을 재해석하지 않음 |
| 추진 추력 | 제공 ENG 파일 | ENG 선택 시 수직 1차원 상승만 계산 |
| 서보 | ST3235 제조사 참조 자료 | 6.5 V 실제 부하 성능 미측정 |
| 드럼·줄 | 일정 반지름, 유격·선형 탄성 | 실제 드럼 지름·브라이들 하중 미확정 |
| 캐노피 | 양력·항력과 경험적 차등 당김 선회 | 제품별 계수·자유 비행 안정성 미검증 |
| 바람 | 평균 + 고도 전단 + 상관 돌풍 | 현장 기상 자료와 공간 난류가 아님 |
| 센서 | 주기·지연·잡음·편향·GPS 끊김 | 장착 센서의 측정 오차 자료가 아님 |

## 모터와 줄 — `actuator.py`

서보의 상태는 실제 각도·각속도·도착 대기 명령 큐다. 지령을 위치 분해능으로 양자화하고 지연 후 적용한다. 목표까지의 거리로 감속 속도를 정하고 가속 한계를 적용한다. 감기 속도는 부하 토크가 정지 토크에 가까워질수록 감소한다. 목표·끝단에서는 속도를 0으로 제한한다.

```text
권취량 = 반지름 × 모터 각도(rad)
줄 이동량 = 권취량 / 도르래 비율
유효 당김 = max(0, (줄 이동량 − 유격 − F0/줄 강성) / (1 + 당김 강성/줄 강성))
장력 = F0 + 당김 강성 × 유효 당김
필요 토크 = 장력 × 반지름 / (효율 × 도르래 비율)
감기 속도 한계 = 무부하 속도 × max(0, 1 − 필요 토크/정지 토크)
```

기본 지연 0.04 s, 가감속 900°/s², 드럼 반지름 10 mm는 시험 가정이다. 위치 분해능은 360°/4096 참조다. 12 V 자료의 30 kgf·cm와 45 rpm을 각각 2.941995 N·m, 270°/s로 환산했다. 회로도 공급 6.5 V와 자료 전압을 별도로 기록하며 자동 전압 환산은 하지 않는다.

위치 유지는 이상적 브레이크다. 역구동·전류·발열·전압 강하·기어 탄성·다층 감김은 계산하지 않는다. 풀기와 감기의 상세 모터 전기 동역학도 재현하지 않는다.

## 회수 비행 — `aerodynamics.py`, `model.py`

상태 벡터는 `[대기속도 V, 경로각 γ, 대기상대 방위 ψ, 동 E, 북 N, 고도 h]`다. 양력·항력은 동압과 설정 계수로 계산한다. 평균 당김은 CL/CD를 바꾸고 차등 당김은 경험적 선회율을 만든다.

```text
평균 당김 = (좌 + 우) / 2
선회율 목표 = turn_gain_rad_s_m × (우 − 좌)
선회율은 turn_time_constant_s의 1차 지연으로 목표를 추종
뱅크각 ≈ atan(V cos(γ) × 선회율 / g)
```

운동방정식은 RK4로 적분한다. 각 단계 안에서는 서보·조향 상태를 고정한다. 기체 방위는 공기상대 속도 방향을 별도 시정수로 따라가는 경험적 상태다. 돌풍으로 속도 방향이 변한 것을 즉시 기체 자이로 회전으로 취급하지 않는다. 관성모멘트·공력 모멘트를 이용한 강체 6자유도 해석은 아니다.

## 바람과 관성 — `environment.py`

바람은 공기가 이동하는 방향이다. `wind_east_mps=+3`은 동쪽으로 움직이는 바람이다. 기본 바람에 고도/100 m × 전단을 더하고, 0.1초 격자의 OU 상관 돌풍을 선형 보간한다. 밀도는 지정된 상수다.

```text
지상 속도 = 대기 상대 속도 + 바람
바람 물질미분 = ∂W/∂t + 수직 속도 × ∂W/∂h
```

`wind_inertia_enabled=1`이면 바람 물질미분을 대기 상대 속도·방향 방정식에 반영한다. 질량의 지상 속도가 풍속 변화만큼 즉시 뛰는 것을 막는 항이다. 수직 바람, 수평 공간 난류, 천의 국부 공력과 변형은 해석하지 않는다. 0은 이류만 더하는 비교 모드다.

## 센서 — `Sensors`

센서는 참 상태를 표본화해 잡음과 편향을 더하고, 정해진 지연 뒤 제어기에 전달한다. 각 센서는 독립 주기와 큐를 갖는다.

| 항목 | 기본 시험 가정 |
| --- | --- |
| GPS | 5 Hz, 지연 0.2 s, 위치 백색 잡음 σ=1.5 m |
| GPS 느린 편향 | OU σ=0.8 m, 상관 시간 30 s |
| 추정 방위·자이로 | 50 Hz, 지연 0.02 s |
| 방위 | 백색 잡음 σ=0.8°, 고정 편향 0.3° |
| 자이로 | 백색 잡음 σ=0.2°/s, 고정 편향 0.1°/s |
| 기압 고도 | 10 Hz, 지연 0.05 s, 잡음 σ=0.5 m |

원시 가속도·자력계·자이로 융합은 구현하지 않는다. 센서 잡음, 지연, GPS 끊김을 바꿔 폐루프 제어의 영향을 비교한다.

## 캐노피는 실제로 조향 가능한가

아직 확인되지 않았다. 링크 제품은 두 줄 카이트이고, 별도 후연 브레이크를 가진 회수용 파라포일과 같은 응답이라고 확정할 수 없다. 기본 유효 면적 1.8 m², CL=0.8, CD=0.3, 선회 이득 4 rad/s/m는 보정 가정이다.

`rigging` 선택은 실제 줄 연결 방식을 기록할 뿐 공력 계수를 자동 확정하지 않는다. 기본 조종줄 하중 비율 0.15도 미측정이다. 두 줄이 전체 중량을 받는 구조라면 하중을 다시 측정해야 한다. 브라이들 각도와 좌우 비대칭 하중은 현재 단순 장력식에 없다.

**가정 8가지 비교**는 현재 설정, 선회 효과 절반·없음·반대, 모터 성능 절반, 명령 지연 최소 0.2초, 조종줄 전체 하중, 센서 오차 증가를 비교한다. 특정 시드의 결정론적 비교이며 실제 성공 확률이나 신뢰구간이 아니다.

## 실측 보정 순서

1. 실제 공급 전압과 부하 조건에서 지령·피드백 각도·시간·전류를 기록해 서보 지연·속도·토크를 식별한다.
2. 모터 각도별 권취량, 캐노피 조작부 변위와 좌우 장력을 측정해 드럼·유격·탄성 모델을 맞춘다.
3. 실제 매달리는 질량과 브라이들·드로그 상태를 확인한다.
4. 안정 비행 속도·하강률과 차등 당김별 선회 방향·이득·시정수를 식별한다.
5. 식별에 사용하지 않은 기록으로 예측을 비교한 후 제어 이득을 검토한다.

출처와 전체 수식은 [기술 참고](reference.md)에 있다.
