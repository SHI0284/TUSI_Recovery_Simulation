# 시뮬레이션 실행 흐름

## 한 번의 계산과 화면 재생

`server.py`가 설정을 받고 `model.simulate()`를 호출한다. 물리 상태를 적분하면서 매 시점의 가상 센서 관측과 제어 지령을 계산한 뒤 전체 시계열을 반환한다. 브라우저는 이 결과를 시간 슬라이더에 맞춰 재생한다. 재생 속도는 계산 시간 간격이나 제어 주기를 바꾸지 않는다.

```mermaid
flowchart LR
  A["설정·ORK·ENG"] --> B["상승 결과와 회수 초기조건"]
  B --> C["센서 → PD → 서보 → 비행 적분 반복"]
  C --> D["미션 시간축 구성"]
  D --> E["3D·그래프 재생 / CSV·JSON 저장"]
```

## 두 시간축

| 시간 | 0초의 의미 | 사용하는 항목 |
| --- | --- | --- |
| T | 추진 모터 점화 | 전체 미션, ORK 상승, 전체 미션 CSV |
| R | 캐노피 안정 비행 시작 | 회수 시계열, 수동 입력 시간, GPS 끊김 시간 |

기본 ORK의 최대 고도 샘플은 T=9.506 s, 가정 전개 시간은 3 s이므로 R=0은 T=12.506 s다. ORK 최고점 이벤트의 9.556 s와 최대 고도 **샘플** 시각을 구분한다.

발사대 대기 → 추력 상승 → 관성 상승 → 전개 → 안정화 → 회수 제어 → 착지 순서다. 전개 구간은 고도 손실·시간을 지정한 시각적 연결이며 개방 충격의 물리 적분이 아니다. 회수는 이미 팽창된 정상 활공으로 시작한다.

## 계산 모드

| `mode` | 동작 |
| --- | --- |
| `target` | 지연·잡음이 있는 GPS와 방위·자이로를 사용해 목표 위치 추종 |
| `manual` | 지정 시간 동안 좌우 고정 회전각 입력 |
| `neutral` | 좌우 중립, 무조향 기준 |
| `heading` | 물리 모델의 참 방위로 고정 방위를 추종하는 이상적 비교 모드 |

`target` 제어기는 참 위치·참 바람을 읽지 않는다. `heading`은 센서 기반 제어와 비교하기 위한 이상 조건이며 실제 센서 제어로 해석하면 안 된다.

`initialization=ork`는 저장 상승 결과를 재생한다. `measured` / `theoretical`은 해당 ENG 추력으로 1차원 수직 상승을 계산한다. ENG 모드는 횡풍·자세를 적분하지 않는다.

## 출력

| 파일 | 내용 |
| --- | --- |
| `trajectory.csv` | R 시간의 위치·속도·모터·센서·제어 시계열 |
| `control_log.csv` | 실제 제어 갱신 시점의 관측값, PD 항, 지령 |
| `mission.csv` | T 시간의 전체 단계, 자세·전개 표시와 근거 |
| `result.json` | 적용 설정, 경고, 보정 상태, 결과 전체 |
| `sources.json` | ORK와 ENG 요약 |
| `angle_sweep.csv` | CLI `--sweep`의 회전각별 결과 |

`landed=false`이면 마지막 위치는 착지점이 아니라 계산 종료점이다. 목표에 가까이 지나간 거리와 최종 착지 오차는 다르다. 현재 제어에는 고도별 최종 접근·플레어가 없어 목표 주변을 선회하다 착지할 수 있다.

화면의 회전각 비교는 30초 종료점 기준이다. CLI `--sweep`은 설정한 `duration_s` 기준이다. 착지 시각이 다른 결과는 동일 시간의 변위로 비교하지 않는다.

## 재현과 개발

바람·센서의 난수 시드를 고정하면 같은 설정에서 같은 계산 결과가 나온다. 비교 시 설정 JSON과 출력 JSON을 함께 보존한다. 같은 바람 시드라도 비행 고도가 달라지면 고도 전단 때문에 풍속이 달라질 수 있다.

실행 의존성은 Python 표준 라이브러리와 저장된 Three.js다. 코드를 수정할 때만 선택적으로 포맷 도구를 설치한다.

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements-dev.txt
.venv/bin/python -m black simulation
npm ci
npm run format
python3 -m unittest discover -s simulation/tests -v
```
